# VIO · 皮具定制工坊

可直接放到 GitHub Pages 的纯静态 3D 卡包定制站。无需 API Key、服务器、构建工具或外部 CDN。

## 本地运行

在项目目录运行 `python3 -m http.server 8000 --directory dist`，浏览器打开 `http://localhost:8000`。不要双击 index.html，浏览器会限制本地 ES Module。

## GitHub Pages

把源码包内的项目文件上传至仓库（包含隐藏的 .github 目录）。仓库 Settings → Pages → Source 选择 GitHub Actions。main 分支推送后，提供的 workflow 会发布 dist。网站不依赖 Sites。

## 修改入口

- `dist/index.html`：页面、VIO 标识、参考照片、定制控件。
- `dist/style.css`：样式、响应式布局、部位选择器。
- `dist/app.js`：皮料/颜色数据、材质配置、几何、边油、缝线、烫印与交互。
- `dist/reference.jpeg`：用户实物参考；其中 PEA 仅为照片原有烫印。
- `dist/vendor/`：本地 Three.js 0.180.0、OrbitControls 和 MIT 许可证。
- `.github/workflows/pages.yml`：GitHub Pages 发布配置。

## 皮面反射与无投影（v7）

移除地面接影平面，并关闭阴影投射。保留正常的表面明暗、颗粒起伏、边油与烫印反光。

皮面不再把照片的明亮高光直接解释为高峰：在去除低频光照后，用暗部沟槽构建浅凹、圆顶的估计高度，再按统一的物理尺度推导 OpenGL 切线法线。高度参数是视觉重建估计，不是品牌皮料的测量值。移除粗网格对同一份微纹的再次位移，避免重复起伏和采样混叠；圆边、轻微鼓面及装饰线仍为真实几何。

皮面清漆层设为零，提高粗糙度并减弱镜面反射；仍为每种皮料保留不同的细纹尺度与光泽。环境改为连续的宽幅柔光，不再使用 RoomEnvironment 中硬边灯箱的反射。边油保持独立光泽。采样来源不变。

## 光照与 Swift 修正（v6）

`dist/studio-lighting.js` 提供跟随观察方向的偏轴主光、补光和下方补光；每帧随 OrbitControls 更新，环境反射同样随观察方向调整。正背面和左右侧拥有一致的照明基准，保持局部起伏与角度反射。边油曲面的三角形绕序已纠正，法线朝向外部。底色材质去除固定的照片高光，只保留较弱沟槽遮蔽。

Swift 改用棕色 Glenan Compact 钱包的清晰背面皮面，减小采样放大比例并单独降低几何微起伏。表面仍保留细孔及宽柔反射。

## 材质与结构更新（v5）

全部五种改用 Hermès 官网包款/手包的皮面特写：Togo / Sac a Dépêches 29；Epsom / Sac a Dépêches 24；Swift / Glenan Compact；Evercolor / Faubourg Express；Chèvre Mysore / Geta。羊皮按官方身份显示为 Mysore，移除 Alran Sully。完整来源与裁取区域见 `dist/materials/SOURCES.md`。

在原始宽高比下采样，去除大范围光照，重建 2048×2048 的整面底色和法线；无周期包裹的拼接控制可见重复，增强颗粒轮廓、起伏及局部反射。材质预先生成，以 WebP 分发，用户设备不再执行纹理拼接。法线及数据图使用无损编码；粗糙度与几何高度图 512×512 控制显存占用。可选重新生成：安装 @napi-rs/canvas 和 Pillow，运行 `node scripts/bake-materials.mjs` 再运行 `python scripts/encode-materials.py`。发布静态成品无需安装这些工具。

`dist/leather-geometry.js` 采用加密网格、圆边、轻微鼓面（v7 将微颗粒统一交给法线，避免重复位移）。卡包成品尺寸为 107 × 70 mm，模型单位统一换算毫米，每片皮厚约 1 mm。缝线距边缘 3 mm；装饰线只有无/单线，本色，线宽 1 mm，启用时线外侧到皮边的窄条使用无纹理皮面。卡位开口厚度采用圆形边缘。移除双线、金色线、银色线及相应 API 参数。烫印字样的金/银选项不受影响。

## 现有功能

- 背板、上层卡槽、下层卡槽分别选择 Togo、Epsom、Swift、Evercolor、Chèvre Mysore 中的任一种，并各自独立配色。
- 从五张皮料实拍提取表面细节，保留各自的纹理，采用不同半哑光/柔光反射。
- 侧边和底边用一体边油曲面覆盖叠层接缝，开口通过圆边几何呈现边油，边油颜色独立可选。
- 自定义最多 6 位英文字母/数字，支持烫金、烫银、素压视觉效果；默认留空。
- 拖动旋转、缩放、四个预设视角、手机布局、配色预设和恢复初始。
- 兼容时渐进注册 WebMCP 读取/配置工具，使用与 UI 相同的状态及严格验证。

## 材质与模型边界

全部材质照片来自 Hermès 官网明确标注品种的产品。照片提取、扩展与凹凸重建不是测量扫描；2048 px 是材质成品尺寸，不是原始采集分辨率。原图光照、拍摄透视、品牌皮料的不同批次都会影响重建。显示颜色为搭配预览。

卡包按 107 × 70 mm 建模；每层 1 mm、缝线边距 3 mm 和装饰线宽 1 mm 均为预览比例。不是生产版型。素压字样仍为示意。无订单或支付功能。

## 验证范围

验证了 1 mm 壳体厚度、单线贯穿卡位两端、无/单线切换、移除选项与 WebMCP 拒绝无效配置、照片和材质图加载、有效顶点数据。v6 另验证灯光随相机转动、正背面和左右侧照明一致、边油法线朝外，并把实际网格与材质数据导出到独立 EGL 光栅渲染，检查五种皮料各自正面、背面和斜侧面，共 15 组画面；该诊断使用独立 PBR 着色器，不是浏览器截图或 Three.js 最终光照验收。当前 Sites 浏览器预览未运行。


v7 检查：五种皮料的法线方向与高度变化同向；相机正、背、左、右四个方向的补光一致；场景无接影地面、无投影灯光且关闭阴影渲染；保留 1 mm 厚度和 1 mm 单线选项。使用实际材质与网格做独立 EGL 近景/侧面/背面诊断，未进行浏览器最终画面验收；独立着色器不包含网页中完整的环境反射。

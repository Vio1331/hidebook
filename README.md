# Hidebook

纯静态手工卡包定制页。默认四层黑色 Epsom、黑色边油、粉笔白缝线。首页标识仅写 hidebook。四层独立选择 Epsom、Togo、Swift、Evercolor、Mysore 与颜色；另可选择缝线、边油、装饰线和烫金文字。上方旋转预览，下方按部位选择，菜单及前后箭头切换并联动镜头。点击模型也可选中部位。皮料名称上悬停查看信息；手机长按名称查看。保存设计保存在浏览器，可下载 JSON；重新加载从默认搭配开始。

## 运行与发布

`python3 -m http.server 8000 --directory dist`，打开 `http://localhost:8000`。

现有 GitHub Actions 在 main 推送后发布 dist 到 GitHub Pages。无构建步骤，无外部字体或脚本 CDN。

## 文件入口

- `dist/app.js`：定制状态、控件、镜头、皮片、跨层鞍式缝线及实体烫金。
- `dist/leather-geometry.js`：尺寸、曲线、独立开口、R0.5 折边、凹槽、连续斩孔路径。
- `dist/photo-materials.js`：五种皮料的材质参数与用户提供的说明。
- `dist/studio-lighting.js`：柔光环境及随观察方向移动的光源。
- `dist/style.css`、`dist/index.html`：界面和响应式布局。
- `dist/materials/`：保留用户上传原图；baked 中为重建材质。
- `dist/freeman.typeface.json`、`dist/Freeman-Regular.ttf`：Google Fonts 的 Freeman 本地字体与轮廓，许可证见 Freeman-OFL.txt。

## 模型

107 × 70 mm，底角 R10，四片皮厚各 1 mm。名称为底皮、钞位、卡位、下卡位。顶部只用同一皮料的半圆折边；折边端头与侧面由同一整体边油覆盖；钞位开口中央约 1.9 mm，沿缝线及底部闭合。各层顶边水平，开口的立体感只沿厚度方向。边油是一张焊接接合的连续曲面，覆盖整叠皮片的侧面、底面和折边端头；无每层独立条带或内部沟缝。

装饰线距边 2 mm、宽 0.28 mm，真实几何凹槽深 0.10 mm；可关闭。缝线距边 3 mm、直径 0.45 mm。照片对应的连续 U 形路径约 68 针，按全路径闭合后实际间距约 3.356 mm（目标 3.38 mm），各层沿同一斩孔相位衔接；两侧顶部各回两针：顶部一针连续从前孔跨过折边到后孔，其下方只再回一针。双线以恒定横向间距平行排列；麻线以照片中的约 3–4 个可见捻束/短针重建，三股粗捻、螺距 2.6 mm，绞股凹凸与稀疏微法线共同表现纤维，端头埋入斩孔。装饰槽仅改变皮面，线不随槽下凹。

烫金支持最多 7 个英文或数字，包括大小写；输入框下可选金色、银色或热压。金银使用金属反光，三种效果都沿用下卡位的同一皮纹坐标，字内法线幅度保留为皮面 16%，表现压浅而未完全抹平的纹理；热压使用皮料本色，在线性颜色空间乘以 0.50 加深，并保留皮面粗糙度。Freeman 轮廓从皮面切出字形孔，凹肩宽 0.11 mm、深 0.22 mm，金箔为带浅倒角的实体几何，随皮片曲面贴合。留空时不显示。

## 材质重建

使用此次上传、文件名带尺寸的产品照片：Togo Ulysse 22×17；Epsom MC² Euclide 10.5×7.5；Evercolor H Sellier 11×9.2；Mysore Calvi Duo 10.5×7；Swift MagSafe 9.6×6.6。按实物像素宽度校准纹理尺度，裁掉缝线、五金和边缘光影，用对数亮度减低频去除曝光渐变，再以最小误差切缝扩展真实颗粒。Evercolor 改用黑色实拍内部区域，额外校正局部反差，避免区域明暗和颗粒深浅出现块状差异。Epsom 改用颗粒轮廓更清晰的 MC² Euclide 内部区域，估算高度 0.11 mm、法线倍数 1.18，并加强谷底双色层次；粗糙度 0.56、镜面强度 0.42、环境反射强度 0.62，略收敛反光。五种悬停图片统一为黑色，去低频光影并统一曝光。

图集覆盖 160 × 160 mm，法线 4096 px，颜色、粗糙度和作者用高度图 1024 px。所有贴图 ClampToEdge，不周期铺贴；每个皮片使用不同采样偏移。微纹通过物理高度估计生成法线，颜色只保留很弱的沟槽遮蔽，光泽由模型光源产生。照片反推不等同于扫描测量。

重建：`python3 scripts/build-materials.py`，然后 `python3 scripts/optimize-materials.py`，最后 `python3 scripts/build-samples.py`。需要 Pillow、NumPy、SciPy。重建先写无损中间图，再优化网页体积。

检查：`node scripts/check-geometry.mjs`，覆盖尺寸、四片开口无相交、折边半径、直顶边、面片内部边界全部接合、凹槽开关、连续针数和回针。

## 交互与颜色

颜色仅保留黑色、粉笔白、金色、焦糖色和大象灰，名称和预览 RGB 来自官网 Calvi 的产品颜色缩略图，另核对上传文件对应的 Tarmac、Ulysse 和 Calvi Duo。来源、产品编号和取色区域见 dist/materials/color-reference.json。缝线与皮料、边油共用这五种颜色，默认粉笔白。

所有皮料按钮均有圆角外框；悬停图的皮料名称与皮种居中且不换行。缝线、边油页分别以同款按钮显示「高品质亚麻手缝线」「意大利 FENICE 边油」，暂不配图。所有定制页共用固定两排布局：桌面定制区高 267 px，手机高 251 px（包含菜单、选项和下方空位）。第一排控件居中，第二排颜色对齐；装饰线页保留第二排空位。切换页不改变模型区、菜单、控件和颜色行的位置。定制区靠近页面底部，模型区吸收剩余高度。

OrbitControls 的 wheel 处理会先更新相机，重绘必须响应 change 事件，不能只靠下一帧 update() 返回值判断。现已订阅 change，并开放到 1.25 的近景缩放；初始、重置及部位/正背侧预设距离统一为 9（原有缩小极限）；竖屏视野按水平角度适配，默认完整显示模型。皮面顶点从每片 34,849 减至 18,721，保留凹槽的密集采样和闭合接缝；折边、麻线同时降低冗余网格。

## 本轮验证

Chromium 实际渲染正面、侧面、实体烫金与 320px、390px 手机页面；未出现脚本/着色器错误或手机横向溢出。几何测试另覆盖顶部连续跨线、下方只有一针回线、双线平行、缝线不受装饰槽影响及边油单一连通曲面。浏览器检查覆盖新默认搭配、细粒度滚轮/触控板 pinch 事件后的相机变化与实际重绘，以及材料弹层、缝线与边油两排选项和手机排版。几何检查覆盖 13,348 个层间不相交采样点。

本轮烫金与视角检查：金/银/热压切换保持输入；三者使用同一浅纹理法线及准确的皮纹坐标，热压色值低于皮面。8 个部位、正背侧及重置视角均检查相机距离 9；触控板缩放后检查实际重绘。

布局一致性检查：在 1440、768、390、320 px 四种宽度逐一检查 8 页，定制区高度及上下边界完全相同，第一排中心和颜色圆点顶部对齐；没有水平溢出。缝线只保留五款共用颜色，初始和重置为粉笔白。
